Personal Portfolio Website

A modern, responsive, and professional portfolio website built using HTML, CSS, and JavaScript.

Features

* Responsive Design
* Dark Mode Toggle
* Typing Animation
* Modern UI Design
* Projects Showcase
* Skills Section
* Certificates Section
* Education Timeline
* Internship Experience
* Contact Section
* Smooth Scrolling

Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts

Setup Instructions

1. Clone or download the project
2. Open the project folder in VS Code
3. Install the Live Server extension
4. Right-click `index.html`
5. Click "Open with Live Server"
